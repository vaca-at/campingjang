# 캠핑장 (campingjang.site)

큰법당 템플스테이(templestay.site)의 뼈대를 그대로 가져와 캠핑으로 바꾼 3D 웹앱이에요.

- 디자인 세 가지: 텐트 · 산속 / 캠핑카 · 바닷가 / 카바나 · 별밤(늘 밤)
- 장소 네 곳: 캠프 마당(모닥불 · 의자) · 내 자리 · 물가 · 취사장, 장소마다 동작 다섯 가지
- 들어오면 모두 1번 본 서버. 메뉴 '조용한 서버로'는 사람 적은 서버로
- 채팅 없이 표정(😊 😆 😮 😢 😴 😍)으로 소통, 불꽃놀이는 같은 서버 모두에게 보여요
- 도감: 낚시 · 곤충 잡기 · 요리로 모아요 (이 기기에 저장)
- 음악 · 자연의 소리: 공유마당(CC BY · 공공누리 1유형), Freesound(CC0). 출처는 js/audio.js 의 TRACKS · 메뉴 '자료 출처'

## 파일
- `js/camp.js` 캠프 마당 · 물가 (풍경은 `js/world.js` 그대로, 텐트 · 캠핑카 · 카바나 · 모닥불 · 의자)
- `js/fun.js` 불꽃놀이 · 도감
- `js/data.js` 디자인 · 장소 · 동작 · 표정 · 캠퍼 이름
- `server/` 중계 서버 (Cloudflare Worker `campingjang-rooms`)
